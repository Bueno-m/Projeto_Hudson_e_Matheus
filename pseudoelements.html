Pseudo-elements

Especificidade CSS, os pseudo-elementos (como ::before, ::after, ::first-line, ::first-letter, etc.) têm o mesmo peso que um seletor de elemento (tag) normal.

Pontuação na Especificidade

O cálculo da especificidade no CSS é baseado em um sistema de pontuação hierárquico, geralmente representado por quatro categorias: (a, b, c, d).

  • a: Estilos em linha (inline styles).
  • b: IDs (#exemplo).
  • c: Classes (.exemplo), atributos ([type="text"]) e pseudo-classes (:hover, :focus).
  • d: Elementos (tags) (div, p) e pseudo-elementos (::before, ::after).

Como funciona na prática

Um pseudo-elemento adiciona um ponto na categoria dos seletores de elemento (d).

Seletor Pontuação (a, b, c, d) Explicação
p (0, 0, 0, 1) Um elemento (tag) p.
::before (0, 0, 0, 1) Um pseudo-elemento.
p::before (0, 0, 0, 2) Um elemento p mais um pseudo-elemento ::before.
.container::after (0, 0, 1, 1) Uma classe .container mais um pseudo-elemento ::after.
#header p::first-line (0, 1, 0, 2) Um ID #header, um elemento p e um pseudo-elemento ::first-line.

Resumo

A chave é lembrar que, embora os pseudo-elementos permitam estilizar partes específicas de um elemento, eles não aumentam a especificidade de forma significativa; eles contribuem com o mesmo peso de um seletor de elemento básico. Isso os diferencia das pseudo-classes (como :hover), que têm o peso de um seletor de classe.

Pseudo-elementos Pseudo-elementos iniciam com :: e visam partes “virtualmente” de um elemento. Exemplos:

  • ::before
  • ::after
  • ::first-line
  • ::marker
