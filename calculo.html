Calculo da Especificidade

O cálculo da especificidade é o método formal que o navegador utiliza para atribuir um "peso" a cada seletor CSS. Essa pontuação é usada para determinar qual regra de estilo será aplicada a um elemento quando há um conflito.

Como é calculada

A especificidade é representada como uma sequência de quatro valores, no formato: (a, b, c, d)

Cada letra significa um tipo de seletor:

  • a – Estilos inline (atributo style="" no HTML)

  • b – IDs (#meu-id)

  • c – Classes (.classe), atributos ([type="text"]) e pseudoclasses (:hover, :not())

  • d – Elementos (div, h1, p) e pseudoelementos (::before, ::after)

Quanto maior o número mais à esquerda, maior a prioridade.

Exemplos Práticos

Seletor de Elemento

  • a = 0

  • b = 0

  • c = 0

  • d = 1

Seletor de Classe

  • a = 0

  • b = 0

  • c = 1

  • d = 0

Seletor de ID

  • a = 0

  • b = 1

  • c = 0

  • d = 0

Estilo Inline

  • a = 1

  • b = 0

  • c = 0

  • d = 0

Quem vence?

  • Classe ganha de Elemento

  • ID ganha de Classe

  • Inline ganha de ID
