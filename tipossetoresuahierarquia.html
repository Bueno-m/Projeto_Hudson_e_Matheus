Tipos de setores e suas hierarquias

Quando múltiplas regras CSS tentam estilizar o mesmo elemento, o navegador usa a especificidade para decidir qual regra vence. Ela é calculada em quatro níveis: (a, b, c, d).

1. Seletores de tipo (elementos e pseudo-elementos)

  • Exemplos: p, h1, div, ::before, ::after
  • Especificidade: (0, 0, 0, 1)
  • São os seletores mais fracos.

2. Classes, pseudo-classes e atributos

  • Exemplos: .card, :hover, [type="text"]
  • Especificidade: (0, 0, 1, 0)

3. IDs

  • Exemplo: #menu, #principal
  • Especificidade: (0, 1, 0, 0)

4. Estilos inline

<p style="color: red;">Exemplo</p>

Especificidade: (1, 0, 0, 0)

5. O curinga: !important

!important supera quase tudo, mas deve ser usado com cuidado.

Hierarquia (da mais fraca para a mais forte)

  1. Seletores de elemento
  2. Classes, pseudo-classes e atributos
  3. IDs
  4. Estilos inline
  5. !important

Metáfora rápida

Elementos = estagiários;
Classes = funcionários experientes;
IDs = gerentes;
Inline = diretor;
!important = dono da empresa.
