Definição

A especificidade no CSS é o algoritmo que o navegador usa para decidir qual regra CSS aplicar quando múltiplas regras apontam para o mesmo elemento.

Para definir de uma forma mais clara:

  • Cada seletor do CSS recebe um "peso" baseado no quão específico ele é (os IDs pesam mais, depois classes, atributos, pseudo-classes, depois os tipos de elementos).

  • Quando dua regras que se conflitam se aplicam ao mesmo elemento para a mesma propriedade, a regra com maior especificidade vence.

    Essa regra ajuda a garantir que estilos mais específicos tenham prioridade sobre estilos mais gerais, permitindo um controle mais preciso sobre a aparência dos elementos em uma página web.
