Armadilhas Comuns

1. Uso exagerado de IDs

IDs possuem uma especificidade muito alta. Quando usados demais, tornam o CSS rígido e difícil de sobrescrever, levando a uma verdadeira “guerra de especificidade”.

2. Criar seletores excessivamente longos

#header nav ul li a span

Seletores longos são muito específicos, porém frágeis. Pequenas mudanças no HTML podem quebrá-los, além de dificultar entender qual regra está prevalecendo.

3. Resolver tudo com !important

Abusar de !important deixa o CSS difícil de manter. Quando tudo é “importante”, nada é — e sobrescrever estilos se torna complicado.

4. Achar que :not() aumenta a especificidade

O seletor :not() não aumenta a especificidade por si só. Apenas os seletores dentro dele contam.

5. Esquecer que estilos inline têm prioridade alta

Estilos colocados diretamente no elemento (style="...") possuem alta prioridade, o que pode causar confusão ao tentar entender por que regras externas não estão sendo aplicadas.
